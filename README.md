# الأُنس بالله · Al-Uns Billah

تطبيق مجاني للقرآن والأذكار ومواقيت الصلاة، بلا إعلانات ولا تتبّع (يُكتب أيضًا: الانس بالله، الأنس بالله، Al Uns Billah؛ واسمه السابق «رفيق المسلم» Muslim Friend).

A free Quran, athkar and prayer-times app for Android, with no ads and no tracking.
